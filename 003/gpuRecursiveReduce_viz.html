CUDA 嵌套归约（Nested Recursive Reduce） gpuRecursiveReduce

用「折纸」的方式理解：每次把数组对折相加，减半后再递归启动子 Kernel， 直到只剩 2 个元素，写出最终和。下方可以逐步播放。

1 一句话直觉

📄

对折相加

数组长度 isize，步长 istride = isize/2。前半段每个位置加上后半段对应位置的值。

🔁

线程 0 启动儿子

本层加完后，只有 tid==0 会再 launch 一个更小的 kernel： <<<1, istride>>>，处理半长数组。

🏁

剩 2 个就收工

当 isize == 2 时不再递归，直接 *odata = idata[0] + idata[1] 写出结果。

核心公式

        

          

            
每层归约

            istride = isize >> 1   // 除以 2
            if (tid < istride)
              idata[tid] += idata[tid + istride]
          

          

            
递归启动（仅 tid==0）

            gpuRecursiveReduce
              <<<1, istride>>>
              (idata, odata, istride);
          

          

            
终止条件

            if (isize == 2 && tid == 0)
              *odata = idata[0] + idata[1];

和普通归约差在哪？

        

          

            传统归约：一个 kernel 里用循环
            for (stride = n/2; …) 在 block 内反复折半，一次 launch 搞定。
          

          

            嵌套归约：每一折半都是新的子 kernel
            （Dynamic Parallelism）。父 kernel 的线程 0 当「调度员」，一层层往下派任务，
            直到 base case。调用关系形成一棵单链递归树（每层只有 1 个子调用）。
